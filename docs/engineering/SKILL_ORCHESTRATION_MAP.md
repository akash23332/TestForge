## 2. Evidence Categorization Definitions

In accordance with Section 2.4 of the Master Specification, the states of all skills are categorized under the following strict classifications:

1. **Skill Discovered:** Path to skill directory or CLI binary located and confirmed on host.
2. **Skill Instructions Read:** Full text of `SKILL.md` inspected and parsed by the agent.
3. **Skill Workflow Followed:** Architectural rules, checklists, and methodologies defined in `SKILL.md` applied directly to current code and documents.
4. **Skill Tool Actually Invoked:** CLI command or script associated with the skill executed via terminal tool.
5. **Skill Invocation Failed:** CLI command triggered but blocked by environment, authentication, or sandbox permissions (explicitly recorded with error output).
